# 🏢 Gestion des Employés

## 📖 Présentation du projet
Ce projet est une application de gestion du personnel développée en Python. Elle permet de gérer efficacement les employés et les départements d'une entreprise. L'application fonctionne entièrement en mode console (terminal) et a été conçue en appliquant les principes de la Programmation Orientée Objet (POO) et les bonnes pratiques de gestion de versions avec Git et GitHub.

## 🎯 Objectifs
À l'issue de ce projet, nous avons démontré notre capacité à :
- Concevoir une application orientée objet (Classes, Héritage, Encapsulation, Polymorphisme).
- Organiser un projet Python de manière professionnelle et modulaire.
- Manipuler des fichiers JSON pour la persistance des données.
- Gérer les exceptions de manière robuste (`try`, `except`, `finally`, `raise`).
- Utiliser Git pour le suivi des versions (commits, branches).
- Héberger le projet sur GitHub et travailler de manière collaborative (Pull Requests).

## ✨ Fonctionnalités
L'application propose un menu interactif permettant de :

**1. Gestion des employés**
- Ajouter un nouvel employé.
- Modifier les informations d'un employé.
- Supprimer un employé.
- Rechercher un employé par son matricule.
- Afficher la liste complète des employés.

**2. Gestion des départements**
- Ajouter, modifier et supprimer un département.
- Afficher tous les départements.
- Affecter un employé à un département.

**3. Statistiques**
- Afficher le nombre total d'employés.
- Calculer le salaire minimum, maximum et moyen.
- Calculer la masse salariale totale.
- Afficher le nombre d'employés par département.

**4. Sauvegarde automatique**
- Sauvegarde des données dans des fichiers JSON (`employes.json`, `departements.json`).
- Rechargement automatique des données au démarrage de l'application.

## 🛠️ Technologies utilisées
- **Langage :** Python 3
- **Gestion de versions :** Git
- **Hébergement :** GitHub
- **Format de données :** JSON

## 📥 Instructions d'installation et d'exécution

Pour faire fonctionner ce projet sur votre machine locale, suivez ces étapes :

1. **Cloner le dépôt :**
   ```bash
   git clone https://github.com/amitaamita/Gestion__Employes.git
   ```

2. **Se déplacer dans le dossier du projet :**
   ```bash
   cd Gestion__Employes
   ```

3. **Lancer l'application :**
   ```bash
   python main.py
   ```
*(Note : Aucune bibliothèque externe n'est requise, seules les bibliothèques standards de Python sont utilisées).*
